# Licensing FAQ

## n8n-nodes-persona Licensing Frequently Asked Questions

### General Questions

#### Q: What license is this software under?
**A:** n8n-nodes-persona is licensed under the Business Source License 1.1 (BSL 1.1). This is a source-available license that allows free use for non-commercial purposes while requiring a commercial license for production use by for-profit organizations.

#### Q: Is this open source?
**A:** BSL 1.1 is a source-available license, not an open source license. However, the software will automatically convert to the Apache 2.0 license (which is open source) four years after each version's release date.

#### Q: Can I view and modify the source code?
**A:** Yes! The source code is fully available. You can view, modify, and create derivative works for non-production purposes without any license fees.

### Commercial License Requirements

#### Q: When do I need a commercial license?
**A:** You need a commercial license if:
- You are a for-profit organization (corporation, LLC, partnership, sole proprietorship, etc.)
- You are using the software in a production environment
- The software is serving end users or customers in a live environment

#### Q: What counts as a "production environment"?
**A:** A production environment is any deployment that:
- Serves real end users or customers
- Processes live data
- Is part of a commercial service or product
- Is not explicitly designated as development, staging, or testing

#### Q: How much does a commercial license cost?
**A:** Commercial license pricing varies based on your organization's size and needs. Contact licensing@velobpa.com for a quote tailored to your situation.

#### Q: Can I try before I buy?
**A:** Absolutely! You can fully evaluate the software in development and staging environments before purchasing a commercial license.

### Technical Questions

#### Q: Does the license affect how I use the n8n workflows?
**A:** No, the license only covers the n8n-nodes-persona package itself. Your workflows, data, and other n8n nodes are not affected by this license.

#### Q: Can I modify the code for my organization?
**A:** Yes, you can modify the code. If you're using it in production as a for-profit organization, you'll still need a commercial license for the modified version.

#### Q: Are there any telemetry or license enforcement mechanisms?
**A:** No. This software contains no DRM, telemetry, call-home functionality, or license enforcement code. Licensing is handled on an honor system with informational notices only.
